# ChatCards

**Turn simple commands into stylish cards.**

ChatCards is a userscript project designed to transform simple text commands into visually appealing cards, with support for Discord-friendly formatting and hosted card previews.

## ✨ Features

- 🎨 Customizable card layouts and styles
- 📝 Titles, descriptions, and formatted text
- 🖼️ Image support
- 🔗 Links and buttons
- 💬 Discord-friendly `!servercard` formatting
- 🌐 Hosted cards with shareable URLs
- 🛠️ Tampermonkey userscript integration

## 🚀 Project Goals

ChatCards aims to make creating and sharing rich-looking cards easy, while keeping them accessible across Discord servers without requiring everyone to install the userscript.

## 🧰 Planned Technologies

- HTML, CSS, and JavaScript
- Tampermonkey
- Netlify hosting and functions

**In development.** Features and hosting integration are being built.
